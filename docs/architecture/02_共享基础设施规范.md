# AI Game Lab 共享基础设施规范

## 1. 目标

所有 Agent 必须最大化复用已有基础设施。

---

# 2. 核心共享模块

当前平台核心：

core/
├── agent-runtime
├── llm
├── tool
├── event
├── project
├── experiment
├── simulation
├── config
└── approval

---

# 3. LLM

统一：

LlmGateway

实现：

DeepSeekClient

未来可以：

ClaudeClient
OpenAIClient
LocalModelClient

但业务 Agent 不允许依赖具体 Provider。

---

# 4. Tool Registry

所有 Tool 统一注册。

Tool 必须：

- 唯一 name
- JSON Schema
- requiresApproval
- execute()
- ToolResult

禁止 Agent 内部私有 Tool 实现绕过 Registry。

---

# 5. Event

所有 Agent 活动统一产生：

AgentEvent

例如：

AGENT_STARTED
STEP_STARTED
LLM_CALLED
TOOL_CALLED
TOOL_COMPLETED
TOOL_FAILED
APPROVAL_REQUIRED
AGENT_COMPLETED
AGENT_FAILED

---

# 6. Experiment

Experiment 是跨 Agent 的共享能力。

Designer 可以创建 Experiment。

Tester 可以创建 Experiment。

Simulation 可以执行 Experiment。

Research 可以保存实验相关资料。

---

# 7. Project

所有数据必须绑定 Project。

推荐：

project
project_artifact
project_config
project_run

如果当前数据库设计尚未包含 Project，应在真正需要多项目管理时通过独立 Task 增加。

不得为了本规范直接擅自修改当前数据库。

---

# 8. Artifact

Agent 产生的结果统一视为 Artifact。

例如：

- Design Document
- Research Report
- Test Report
- Build
- Screenshot
- Log
- Experiment Result

Artifact 应能够关联：

projectId
agentRunId
createdAt

---

# 9. 数据访问

Agent：

Agent
↓
Service
↓
Repository
↓
Database

禁止：

Agent
↓
JDBC

---

# 10. 共享基础设施修改规则

如果新增 Agent 发现已有基础设施不足：

优先：

扩展现有模块。

禁止：

复制一个新的实现。

例如已有：

AgentRuntime

不要新增：

TesterRuntime。
