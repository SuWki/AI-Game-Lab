# 2. Agent

所有 Agent：

运行于 Backend JVM。

不单独启动服务。

---

# 3. 为什么不微服务

当前阶段：

- 用户数量低
- Agent 数量少
- 数据规模低
- Tool 调用量低
- 主要目标是验证产品

微服务只会增加：

- 部署复杂度
- 网络调用
- 日志复杂度
- Debug 成本
- 数据一致性问题

因此 MVP 禁止无必要微服务化。

# 8. Worker 化

当出现：

- 长时间 Simulation
- 游戏自动测试
- 自动 Build
- 大量 Research

可以把耗时任务迁移到：

Worker

架构：

Backend
↓
Task
↓
Worker

但 Agent Runtime 本身不应该因为 Worker 化而复制。
