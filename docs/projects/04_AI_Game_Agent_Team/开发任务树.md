# QA 演进任务与验收

以下是待实施任务，Phase 1–3 历史记录见 [模块入口](README.md)。

| ID | 目标与修改范围 | 依赖 | 退出条件 |
|---|---|---|---|
| Q-N1 | 编排 deadline/累计预算持久化，Orchestrator/Repository/迁移 | Runtime 已有恢复契约 | 角色启动前后重启不重置预算；父任务取消后不启动新角色；实际子 Run 状态可见 |
| Q-N2 | 固定候选/验收/证据快照，Gate 服务与版本化 DTO | VAL-01、生产交付元数据 | 同候选后续新增实验不改变旧判定；缺证据为不足；模拟/真实指标不混用 |
| Q-N3 | 生产评估与人类接受展示 | Builder 候选、Tester 证据 | UI 可回溯规格→构建→检查→Finding；人工接受保留自动 FAIL 与原因 |

验收矩阵：角色全结束但有未测必需项，不能 PASS；角色意见一致但无原始证据，不能 PASS；正常产物却来自旧构建，拒绝；拒绝/超时/取消流程有结果；确定性判定不因语言模型措辞改变。旧 Phase 3 判据与已保存结果继续通过兼容测试。真实模型至少覆盖正常候选、问题候选和证据不足候选，记录预算和人工修正，不靠固定 Fake 顺序证明效果。
