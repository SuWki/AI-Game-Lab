## 最终验收清单

功能：规格接受范围完成；输入、核心循环、结算、重开可操作；新游戏非只改名字/颜色；报告明确占位与未实现内容。

可靠性：工具调用结果进入下一轮；未授权文件不能写；模型不能改冻结验收；执行/构建版本固定；取消/崩溃后不重复未知副作用；失败轮次和费用累计不被新 Run 清零。

质量：两件作品都通过独立自动检查与人类玩法/视觉评审；记录负例（范围过大、缺素材、无法修复、用户拒绝），不得丢弃失败生产来夸大成功率。固定任务实测耗时与成本，先建立基线再设 SLO。

交付：在独立干净目录按 README 和锁文件复建，可运行入口与已验收候选一致；源码/构建/素材清单/规格/测试/已知问题齐全。Test PASS、QA 建议与人类接受分别可查。
