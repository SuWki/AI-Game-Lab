# Builder 技术设计

层级：Project。2026-11-12，**全部新增 Builder 流程为待实施**。依赖 [生产契约](../../platform/GAME_PRODUCTION_CONTRACT.md)、[可信验证](../../platform/IMPROVEMENT_VALIDATION_DESIGN.md) 和 [Runtime](../../platform/AGENT_RUNTIME_RECOVERY.md)。

## 模块与复用

在现有后端增加 builder 业务模块与必要服务；复用 Task/Run/Step/Tool、LlmGateway、Repository、事件、中台。先用确定性的阶段协调服务，不建立另一个 AgentLoop 或通用分布式 DAG 引擎。当前 LocalChangeService 是已有版本的提案执行器，不直接承担无基线新建项目。

需要新增的能力：TemplateCatalog、WorkspacePreparation、ProductionCoordinator、CandidatePackaging（逻辑职责，非必须四个新服务类）。准备和命令执行共用本地执行基础设施；新建工作区和已有基线复制采用不同准备策略。文件编辑复用提案/hash/审批原则，不能通过伪造失败测试绕过新建场景。

## 模板与工作区

模板登记固定 commit/hash、锁文件、引擎版本、能力/参数 schema、源文件与资产范围、准备/构建/验证命令、独立验收程序。使用随仓库或操作者登记的模板，模型不能把任意下载地址当可信模板。实例化时生成新的工作区 ID 与输出根，写入范围只在该根内；路径穿越、符号链接、外部目录写入拒绝。

素材清单包含用途、来源、允许使用范围、版本/hash、是否占位。素材生成/导入是可选适配器；没有适配器时使用明示占位素材，不声称已有图像/音频生产服务。新增依赖需要计划中登记并锁定，不能在修复轮次任意升级基础框架。

第一版单用户、同一游戏串行工作区应用，有界执行队列。多件作品顺序生产，每件有独立输出与交付记录；targetId 与工作区隔离不能替代未来 project_id 全域授权，多项目并发须另做迁移。

## 持久化与阶段转换

生产记录保存 mode、简报/规格/验收/模板引用、工作区、阶段、活跃 Run、修复计数、累计预算、候选引用与错误。实现时先提交版本化 schema/DTO 与迁移；可读产物复用 design_document，新增结构化元数据不得伪装已存在字段。

阶段：PREPARING→IMPLEMENTING→VERIFYING→REVIEW→DELIVERED，另有 FAILED/CANCELLED/INTERRUPTED/WAITING_INPUT；它们是生产业务记录状态，不是 Run 新枚举。WAITING_INPUT 表示缺规格或待用户决定，记录待决事项与继续条件。INTERRUPTED 表示进程结束且外部效果待核对，只在人工/确定性核对完成后继续或建立新尝试，不能直接自动重放。

每阶段进入前验证输入版本和前置产物；条件更新领取执行权。实例化按 productionId 幂等；每次文件应用保存 proposalId 和检查点；构建/验证产生独立执行 ID；打包按 candidateId 幂等。重启检查已有外部过程与产物，结果未知则 INTERRUPTED/待核对，不盲目重新应用文件或重新发布。

## 流程与 API 设计要求

创建生产请求只引用已接受简报/模板与范围；查询返回阶段、证据引用和具体缺项；取消传播到受管执行；继续必须保持原规格版本或明确新建版本；获取候选返回包与清单。建议扩展 `/api/productions` 资源族，但**未实现，不能现在调用**。具体 DTO 和错误码沿用 ApiResp/既有错误约定；非法输入、冲突、资源缺失和上游失败区分。

前端工作台需要规格、阶段、预览、差异/审批、测试/QA 与候选下载。预览绑定本次构建，仅回环地址与受管进程；退出清理监听/子进程。先展示真实日志与错误，不能只有一个“生成中”。

## 验证、交付与异常

每次候选依序静态检查→干净构建→启动→独立功能/回归→适用的浏览器/玩法验证。测试数据与程序固定，Builder 写权限不包含独立验收。启动成功不足以证明核心循环完整。规格变更让相关验收重新接受，不能代码失败后直接改验收。

失败保留差异和日志，在预算内新建修复提案；超过最多 5 次修复返回未完成。取消停止新任务并收集当前状态，不清除证据。回滚只恢复受管工作区已知检查点，用户原工作目录不被 hard reset。原生代码执行仍是可信本地环境，不声称 OS 沙箱。

打包只能消费验证过的同一候选，清单包含所有输入/产物 hash、测试与 QA 引用，排除密钥、临时缓存和运行凭据。候选交付保留源码、锁文件、构建、说明、素材清单和已知问题；发布/推送单独授权。
