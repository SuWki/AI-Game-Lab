## 本批实现

- 从已验证的固定包读取 GameSpec，完整列出 acceptanceCriteria，并按需求汇总 PASS/FAIL/PARTIAL/NOT_TESTED；引擎六项检查保持独立，不自动推定规格覆盖。
- DRAFT/ACCEPTED/REJECTED 以 candidate_review 修订追加保存，绑定候选、manifest 和 ZIP 哈希；观察与总结有长度限制，PASS/FAIL 必须有说明，缺项/重复/未知 ID 拒绝。
- expectedRevision 提供并发冲突保护，精确重试不重复写；当前候选/未决工作在接受事务内再次核对。文件和服务读取放在事务外，避免 SQLite 单连接的锁顺序冲突。
- 最新显式接受、完整人工 PASS、固定文件校验和当前 REVIEW 候选共同打开实时门禁。拒绝、后续草稿、新候选、未决修改或包损坏都会阻止当前交付判断；历史意见仍可查。
- 页面支持逐项记录、显式重新载入、历史游标和独立 JSON 回执。原包不改写，包内 humanAccepted=false 保留打包时语义。评审者是操作者标签，不是认证身份；没有新增 Agent 接受/发布工具。
