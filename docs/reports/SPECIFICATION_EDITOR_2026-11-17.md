# 规格编辑入口交付

2026-11-17。在 `/productions` 选择已有任务后，可新建规格或明确载入选中版本编辑。尚无任务时，页面链接到 Workflow 创建任务。表单包含标题、玩法、结算/重开预期、目标玩家与首轮范围、两种机制及模板参数、需求和对应验收项，无需手写 JSON 或调用保存 API。

新建时先保存 ProductionBrief，再用服务端返回的精确 revision/hash 固定 GameSpec 输入。两次写入复用既有 API，不是跨接口事务：若第二次失败，简报可能已经存在；原内容重试复用服务端幂等机制。修订只保存 GameSpec，保留原 inputRefs 和 briefRef，不会改写初次简报。

修订基于明确的 artifactId/expectedRevision 追加。未暴露的已有字段、额外系统与多项验收标准保持原值，原版本及生产引用不变。冲突/失败保留表单，只有成功保存才自动选择新规格。选择不同版本不会自动覆盖正在编辑的草稿；需关闭编辑再明确载入。切换任务会重建该任务的编辑器，本版未提供跨任务草稿持久化。

范围仅支持 web survival-web 参数表单，不支持其他引擎规格编辑，不把未知规格转换为默认模板。每个新增需求附一个浏览器验收项，可修改需求/预期或连同其验收项一起删除；已有多项验收完整展示保留。模板参数空值/越界由表单阻止，服务端仍提供权威校验。新建默认的结算/重开项是可编辑起点，不是已验收结论。

本批不新增数据库表、Agent 工具或 Prompt（仍26/41/16），不调用模型。保存不代表接受或实现；当前仍无正式规格接受状态。Designer 的模型输出自动转换、任意需求自动实现及浏览器规格证据仍需后续开发。
